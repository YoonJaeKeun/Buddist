# 불교 경전 PDF

책처럼 읽고 인쇄할 수 있도록 A4 규격으로 조판한 문서입니다.

- [금강경 — 원문·우리말 풀이·구절별 해설](금강경_원문_우리말풀이_해설.pdf) — A4, 80쪽
- [반야심경 — 전문·우리말 풀이·구절별 해설](반야심경_원문_우리말풀이_해설.pdf) — A4, 25쪽
- [법구경 — 39품 원문·우리말 풀이·게송별 해설](법구경_39품_원문_우리말풀이_해설.pdf) — A4, 408쪽
- [법화경 — 28품 원문·우리말 풀이·문장별 해설](법화경_28품_원문_우리말풀이_해설.pdf) — A4, 713쪽
- [유마경 — 14품 원문·우리말 풀이·문장별 해설](유마경_14품_원문_우리말풀이_해설.pdf) — A4, 268쪽
- [정토삼부경 — 원문·우리말 풀이·문장별 해설](정토삼부경_원문_우리말풀이_해설.pdf) — A4, 200쪽

PDF에는 표지, 차례, 장별 새 쪽 시작, 원문·우리말 풀이·해설 구분, 머리말과 쪽번호가 들어 있습니다. 법구경의 각 품은 새 쪽에서 시작하며, 각 게송은 한 쪽에 모두 들어가면 앞 게송에 이어 배치하고 남은 공간이 부족하면 다음 쪽에서 시작합니다. 법구경 PDF 앞부분에는 [법구경 책머리](../법구경_책머리.md)를 수록하여 경전의 의미, 한역 전승, 팔리어본과의 차이, 39품의 흐름과 읽는 방법을 설명합니다. 이어 [법구경서](../법구경서.md)의 한문 원문·우리말 풀이·해설 전체를 싣고 제1품을 시작합니다. 법화경 PDF는 문서 안내와 28품 구성표에 이어 28개 품별 보강본의 원문·우리말 풀이·문장별 해설을 모두 수록했으며, 각 품은 새 쪽에서 시작합니다. 유마경 PDF도 같은 방식으로 문서 안내와 14품 구성표에 이어 14개 품별 보강본의 216단락을 모두 싣습니다. 정토삼부경 PDF는 [책머리](../정토삼부경_책머리.md)에 이어 《무량수경》 권상·권하, 《관무량수경》, 《아미타경》의 경 본문 전문을 227단락으로 싣습니다. 다섯 원고의 모든 원문 블록은 `scripts/check_passage_coverage.py`로 저본과 대조하여 건너뛴 구간이 없음을 확인했으며, 절 제목마다 새 쪽에서 시작합니다. 원본 Markdown이 바뀌면 저장소 루트에서 다음 명령으로 다시 만들 수 있습니다.

```bash
python3 scripts/build_scripture_pdfs.py
```

특정 경전만 다시 만들 때에는 `--book` 뒤에 경전 이름을 지정합니다. 예를 들어 법화경은 `python3 scripts/build_scripture_pdfs.py --book 법화경`으로 만듭니다.

제작에는 Windows용 Microsoft Edge를 헤드리스로 사용하며, WSL의 파이썬과 Windows의 파이썬 어느 쪽에서 실행해도 됩니다. 한글 조판에는 Windows의 Noto Serif KR·Noto Sans KR 글꼴을 사용합니다.
