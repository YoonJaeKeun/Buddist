# 불교 경전 PDF

책처럼 읽고 인쇄할 수 있도록 A5 판형으로 조판한 문서입니다.

- [금강경 — 원문·우리말 풀이·구절별 해설](금강경_원문_우리말풀이_해설.pdf) — 120쪽
- [반야심경 — 전문·우리말 풀이·구절별 해설](반야심경_원문_우리말풀이_해설.pdf) — 32쪽

두 PDF에는 표지, 차례, 장별 새 쪽 시작, 원문·우리말 풀이·해설 구분, 산스크리트어 풀이, 머리말과 쪽번호가 들어 있습니다. 원본 Markdown이 바뀌면 저장소 루트에서 다음 명령으로 다시 만들 수 있습니다.

```bash
python3 scripts/build_scripture_pdfs.py
```

제작 환경은 WSL과 Windows용 Microsoft Edge이며, 한글 조판에는 Windows의 Noto Serif KR·Noto Sans KR 글꼴을 사용합니다.
