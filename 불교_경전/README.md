## 편집 원칙

1. 원문과 편집자의 번역·해설을 명확히 구분합니다.
2. 원전의 판본과 출처를 기록합니다.
3. 단정하기 어려운 교학적 쟁점은 하나의 해석만 정답처럼 제시하지 않습니다.
4. `공(空)`과 `무상(無相)`을 허무주의로 오해하지 않도록 자비와 실천의 맥락을 함께 살핍니다.

분량이 짧은 경전은 전문을 구절별로 풀이하고, 여러 권으로 이루어진 대형 경전은 전체 구조와 핵심 구절을 이해할 수 있는 안내서로 정리합니다. 생략 없는 한자 원문은 모두 `전문_한자음` 폴더에 권별 파일로 수록합니다.
