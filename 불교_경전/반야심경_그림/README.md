`01`·`02` 두 이미지는 웹에 공개된 원본을 내려받아 보관한 것입니다. 이용 조건이 확인되지 않아 본문 문서에 싣지 않았고, 공개 저장소에도 올리지 않고 로컬에만 둡니다. `03`~`06`은 위키미디어 공용에 퍼블릭 도메인으로 등록된 옛 작품의 사진이며, 본문과 PDF에 실었습니다. 파일의 출처와 소장 정보를 기록했으며, 출처 표기가 곧 재사용 허가를 뜻하지는 않습니다.
